Backend for MIT Generative AI Hackathon project.

This is an app to create quiz from uploaded PDF file.
Motivation is to create quizes and use [Spaced repetition](https://en.wikipedia.org/wiki/Spaced_repetition) to support learning process

Server extracts information from the file and generates quiz.
User can define number of questions.
